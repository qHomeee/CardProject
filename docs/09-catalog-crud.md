# Практика 9 База данных и CRUD каталога

PostgreSQL хранит общие наборы и карточки. FastAPI позволяет скачать набор одним запросом. Каталог читается без регистрации, а запись доступна редактору.

## Миграция базы данных

Alembic применяет миграцию **0001_catalog**. Она создаёт таблицы decks и cards, внешний ключ cards.deck_id и индекс по нему. При удалении набора PostgreSQL удаляет его карточки. Проверки на уровне БД запрещают пустые названия, вопросы и ответы. Длину полей задают столбцы varchar и входные модели.

Операция записи выполняется внутри транзакции. Изменяемая строка блокируется до конца операции. Для скачивания набор и карточки читаются одним SQL-запросом. Карточки упорядочиваются по UUID. Поиск сравнивает нормализованные названия через Unicode casefold, поэтому запрос «ЕВРОПА» находит «Европа», а % и _ считаются обычными символами.

## Доступ к каталогу

| Операции | Условие и результат |
| --- | --- |
| Три маршрута GET | Чтение доступно без регистрации и ключа. |
| Шесть маршрутов POST, PUT и DELETE | Нужен правильный X-Editor-Key. Без него или при неверном значении возвращается 401. |
| Запись при пустом EDITOR_API_KEY | Возвращается 503. Чтение остаётся доступным. |
| Запрос к карточке из другого набора | Возвращается 404. Карточка сохраняется в исходном наборе. |

## Проверки

Проверки выполнены с Python 3.13.15 и PostgreSQL 18.7. На пустой базе миграция применена, откачена и применена повторно. Команда alembic check подтвердила соответствие моделей фактической схеме.

| Проверка | Результат |
| --- | --- |
| CRUD наборов и карточек | Создание возвращает 201 и адрес записи. Изменения читаются из базы. Удаление возвращает 204. |
| Связь набора и карточек | Другой набор даёт 404. После удаления набора связанных карточек в БД нет. |
| Защита записи | Все шесть операций отклоняют запросы без ключа, с неверным ключом и с двумя заголовками. Данные сохраняются. |
| Поиск и поля | Проверены регистр, внешние пробелы, буквальный поиск %, _ и переносы в карточке. |
| OpenAPI и HTTP | Девять операций сверены с контрактом. Каталог, OpenAPI и Swagger UI доступны при локальном запуске Uvicorn. |

Прошли семь проверок pytest. Интеграционные тесты мигрируют отдельные схемы PostgreSQL.

## Воспроизведение

Команды запуска и переменные окружения приведены в **backend/README.md**. Для тестов задайте TEST_DATABASE_URL отдельной базы и выполните **uv run --locked python -m pytest -q**.

Развёртывание FastAPI и PostgreSQL для доступа по HTTPS относится к практике 10.
