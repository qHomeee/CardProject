# Практика 17 Навигация и каталог «Запомни»

Приложение открывает каталог через Navigation Compose 2.9.8. Маршруты нижней панели заданы отдельными типами. При смене вкладки сохраняется её состояние. Системная кнопка «Назад» возвращает с другой вкладки в каталог. [Документация Navigation Compose](https://developer.android.com/guide/navigation/design/type-safety).

## Нижняя панель

| Вкладка | Содержимое |
| --- | --- |
| Каталог | Список серверных наборов, количество карточек и поиск по названию |
| Мои наборы | Список собственных и скачанных наборов из Room |
| Настройки | Маршрут и заголовок раздела |

Поле поиска передаёт новый запрос через 300 мс после последнего ввода. Внешние пробелы убирает SearchCatalog, а сервер ищет подстроку без учёта регистра. Пустой запрос показывает весь каталог. При новом вводе предыдущий запрос отменяется. Текст сохраняется при переключении вкладки.

Использованы поля, карточки, сообщения и цвета дизайн-системы. Реализация сверена с сохранёнными макетами и картой переходов. Подпись поля уточняет, что поиск работает по названию. [Макеты каталога в Figma](https://www.figma.com/design/vGsWHmxJCV73DQ0EIwDe4Z?node-id=22-2).

## Проверка на Android 14

| Действие | Результат |
| --- | --- |
| Открыть приложение с сетью | VPS вернул набор «Столицы Европы» с 12 карточками |
| Ввести запрос без совпадений | Появилось сообщение «Ничего не найдено» |
| Открыть каталог в авиарежиме | Кнопка «Открыть мои наборы» перевела на локальный список |
| Вернуть сеть и нажать «Повторить» | Каталог снова показал набор с сервера |

Отдельный запрос к API с подстрокой «сТоЛиЦы» и внешними пробелами вернул нужный набор. Проверены светлая и тёмная темы. При масштабе текста 200% вкладки размещаются столбцом, описание набора доступно прокруткой.

Прошли 67 JVM-тестов и 18 инструментальных тестов. Проверены восстановление вкладки после пересоздания Activity и возврат в каталог. Debug APK собран, ktlint прошёл. Android Lint показал 0 ошибок и 26 предупреждений.
