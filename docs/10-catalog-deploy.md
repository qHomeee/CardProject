# Практика 10 Ошибки API и развёртывание каталога

Каталог «Запомни» развёрнут на VPS с Ubuntu 24.04. Nginx принимает HTTPS и передаёт запросы FastAPI. PostgreSQL 16.15 работает на том же сервере. Служба приложения запущена в systemd под отдельным пользователем. FastAPI обращается к базе через локальный сокет.

[Публичный каталог](https://153.80.185.223/api/v1/decks) и [Swagger UI](https://153.80.185.223/docs).

## Валидация и ответы об ошибках

API возвращает объект error с полями code и message. При ошибке ввода в fields добавляются путь и пояснение. Сообщения подсказывают, где исправить JSON, заполнить поле или сократить строку. При внутреннем сбое клиент получает общий текст.

| Код HTTP | Когда возвращается |
| --- | --- |
| 401 | Изменение каталога без действительного ключа редактора. |
| 404 и 405 | Нет записи или маршрута либо выбран неподдерживаемый метод. |
| 413 | Тело HTTPS-запроса больше 64 КиБ. |
| 422 | Неверный JSON, UUID или значение поля. |
| 500 и 503 | Внутренний сбой или временная недоступность сервиса. |

Коллекция Postman содержит девять операций каталога и примеры ошибок. Она позволяет проверить чтение без ключа и изменения в отдельной тестовой базе.

## Проверка развёртывания

| Проверка | Наблюдение |
| --- | --- |
| Публичный HTTPS | Каталог, OpenAPI и Swagger UI вернули 200. HTTP перенаправляется на HTTPS. |
| Редакторский доступ | Запись без ключа вернула 401. С ключом созданы набор и карточка. Чтение вернуло карточку. Временный набор удалён. |
| Ошибки ввода и метода | Проверены неверный JSON, длинное название, превышение размера тела и неподдерживаемый HTTP-метод. |
| Сертификат | Let’s Encrypt выпустил сертификат на IPv4. Таймер Certbot включён, пробное продление прошло. |

Локально прошли 11 проверок pytest. В публичном каталоге доступен демонстрационный набор «Столицы Европы» из 12 карточек. Android-клиент сможет использовать этот адрес на этапе подключения к сети.

Порядок установки и команды проверки описаны в **backend/README.md**. Адрес PostgreSQL и редакторский ключ задаются через окружение службы.
