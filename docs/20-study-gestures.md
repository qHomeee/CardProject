# Практика 20 Занятие и жесты

Занятие открывается из собственного или скачанного набора. Очередь фиксируется при запуске и содержит карточки, срок которых наступил. После открытия ответа доступны две оценки. Room записывает оценку и новый срок вместе. При сбое ответ остаётся открыт, а повтор отправляет ту же оценку для той же карточки.

## Распознавание движения

| Действие | Условие |
| --- | --- |
| Нейтральное положение | Экран вверх, Z не ниже 0,80. Модуль X не выше 0,25. |
| Показать ответ | После нейтрали экран вниз с Z не выше −0,80, затем возврат в нейтраль. |
| Вспомнил | После открытия ответа вправо. X не выше −0,50. |
| Нужно повторить | После открытия ответа влево. X не ниже 0,50. |

X и Z — доли длины вектора в координатах экрана. При наклонах нужен Z не ниже 0,40, чтобы отсечь крайние положения. Распознанное положение удерживается не менее 180 мс. После наклона до следующего жеста нужен возврат в нейтраль. Пороги предварительные и будут проверены на телефоне.

Android использует датчик гравитации, а при его отсутствии — сглаженные измерения акселерометра. Подписка работает только в активном занятии на переднем плане. При повороте экрана оси пересчитываются. Для регистрации с SENSOR_DELAY_GAME дополнительные разрешения не запрашиваются. [Координаты датчиков Android](https://developer.android.com/develop/sensors-and-location/sensors/sensors_overview).

## Проверка на Android 14

Занятие прошло в авиарежиме. Кнопки открывали ответ и записывали оценки. Проверены повтор записи после ошибки, исключение будущих карточек и остановка подписки в фоне и в диалоге выхода.

Виртуальные воздействия на акселерометр и гироскоп прошли через Android-адаптер. Переворот открыл ответ, правый наклон записал «Вспомнил». После поворота экрана в альбомный режим ответ остался открыт, левый наклон записал «Нужно повторить». Итог — одна оценка каждого вида.

Прошли 75 JVM-тестов и 23 инструментальных теста. Debug APK собран, ktlint прошёл. Android Lint показал 0 ошибок и 23 предупреждения. [Макеты занятия в Figma](https://www.figma.com/design/vGsWHmxJCV73DQ0EIwDe4Z?node-id=23-1153).

## Сценарий для телефона

1. Включите «Управление жестами» в настройках и начните занятие с двумя доступными карточками.
2. Держите экраном вверх, переверните экраном вниз и верните обратно. Убедитесь, что ответ открылся при возврате.
3. Опустите правый край экрана. После перехода верните телефон в нейтраль, откройте следующий ответ и опустите левый край.
4. Для проверки в альбомном режиме и с выключенными жестами используйте новые карточки. У уже оценённых карточек изменился срок повторения.
