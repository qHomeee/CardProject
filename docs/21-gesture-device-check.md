# Практика 21 Показ ответа при разном хвате

Проверка жестов проводилась на RMX3630 с Android 14. Приложение подписывается на вектор вращения для разворота и на датчик гравитации для наклонов. На телефоне Android зарегистрировал оба датчика с запрошенным периодом 20 мс. При отсутствии вектора вращения сохраняются переворот экраном вниз и управление кнопками. [Датчики движения Android](https://developer.android.com/develop/sensors-and-location/sensors/sensors_motion).

## Исходное положение

Распознаватель запоминает направление экрана, когда телефон ненадолго стабилизируется. Если пользователь поменял хват, направление обновляется после 420 мс устойчивого положения. Так можно начать разворот из вертикального, горизонтального или наклонного положения.

Для переворота вычисляется изменение направления экрана в пространстве. Если телефон держат перед собой, дополнительно сравниваются горизонтальные проекции. Это позволяет распознать разворот при заметном наклоне телефона. Обычное вращение лежащего экраном вверх телефона ответа не открывает.

После подтверждённого разворота распознаватель ждёт 60 мс устойчивого возврата и открывает ответ. Положение от себя, исходная стабилизация и оценочный наклон требуют 180 мс. Разрыв измерений более 300 мс сбрасывает незавершённое движение.

## Результаты проверки

| Проверка | Результат |
| --- | --- |
| Разворот из разных положений | На телефоне открылись 3 из 3 ответов: при вертикальном, наклонном и горизонтальном хвате. Автотесты прошли. |
| Смена хвата до разворота | Автотест подтвердил переход от положения экраном вверх к хвату перед собой. |
| Вертикальный разворот и оценки | На телефоне ответ открывался при возврате. Получено по одной оценке каждого вида. |
| Поворот экрана с открытым ответом | Ответ оставался открыт в альбомной ориентации на эмуляторе. |
| Кнопки при выключенных жестах | Инструментальный тест прошёл без сети. |

Прошли 89 JVM-тестов и 23 инструментальных теста. Debug APK собран, ktlint прошёл. Android Lint показал 0 ошибок и 21 предупреждение.

## Как повторить

1. Включить «Управление жестами» в настройках и открыть занятие со свежими карточками.
2. Держать телефон как удобно. Повернуть экран от себя, ненадолго задержать и вернуть экран к себе.
3. После открытия ответа наклонить верх телефона в сторону нужной оценки или нажать кнопку.
