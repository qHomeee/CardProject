# Практика 16 Локальное хранение Запомни

Приложение хранит наборы и результаты повторения в SQLite через Room 2.8.5. KSP 2.3.6 генерирует код работы с базой. Схема версии 1 сохранена в репозитории. [Документация Room](https://developer.android.com/jetpack/androidx/releases/room).

## Структура базы

| Таблица | Содержимое |
| --- | --- |
| decks | Название, описание и уникальный ID источника для скачанных наборов |
| cards | Вопрос, ответ, ревизия текста и ссылка на набор |
| schedules | Текущий срок и версия расписания карточки |
| reviews | Оценка и рассчитанный результат для конкретной версии карточки и расписания |

Скачанный набор, его карточки и начальное расписание записываются одной транзакцией. Повторное сохранение того же источника возвращает ID существующей копии. При оценке карточки запись оценки и обновление расписания также выполняются вместе. Повтор оценки возвращает сохранённый результат.

Экран «Мои наборы» получает список из Room и предлагает повторить чтение при ошибке. Preferences DataStore 1.2.0 хранит режим темы, настройку жестов и напоминаний. Стартовый экран применяет сохранённую тему. [Документация DataStore](https://developer.android.com/topic/libraries/architecture/datastore).

## Проверка без сети

Эмулятор Android 14 работал в авиарежиме с выключенным Wi-Fi. Тест получил копию набора от подменного источника и записал её в файловую базу. После закрытия и повторного открытия базы карточки, оценка и следующий срок повторения прочитались локально.

Два одновременных сохранения создали одну копию набора. Сбой записи карточки отменил сохранение набора, а сбой записи оценки откатил обновление расписания. После повторного открытия DataStore восстановились тема, настройка жестов и выбранное время напоминания. Экран «Мои наборы» показал сохранённый набор до и после пересоздания Activity.

Прошли 64 JVM-теста и 16 инструментальных тестов. Debug APK собран, ktlint прошёл. Android Lint показал 0 ошибок и 17 предупреждений.

## Повторный запуск проверок

Из папки **android** выполните следующие команды. Для третьей команды запустите эмулятор или подключите Android-устройство.

1. **.\gradlew.bat :domain:test :app:testDebugUnitTest**
2. **.\gradlew.bat :app:assembleDebug :app:lintDebug :ktlintCheck**
3. **.\gradlew.bat :app:connectedDebugAndroidTest**

Сохранение набора и выставление оценки на этом этапе проверены через сценарии доменного слоя. Подключение экранов этих действий относится к следующим практикам.
