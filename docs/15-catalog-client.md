# Практика 15 Сетевой клиент каталога Запомни

Android-клиент читает публичный каталог через Ktor 3.3.3 и OkHttp 5.2.1. Для JSON используется kotlinx.serialization 1.9.0. Koin предоставляет один HTTP-клиент и связывает адаптер с интерфейсом CatalogReader.

## Запросы и данные

| Запрос | Результат |
| --- | --- |
| GET /api/v1/decks | Список наборов с количеством карточек. Подстрока поиска передаётся в параметре q. Пустой запрос отправляется без q. |
| GET /api/v1/decks/{id} | Набор и все его карточки в одном ответе. ID набора сверяется с запрошенным UUID. |

DTO повторяют поля OpenAPI. Мапперы проверяют UUID, уникальность идентификаторов и текст. Порядок наборов сохраняется таким, каким его вернул сервер. Сетевые модели остаются в слое data, сценарии получают модели domain.

Сборка использует адрес [публичного каталога](https://153.80.185.223/api/v1/decks). Для другого сервера передайте HTTPS-адрес свойством Gradle **zapomni.catalogBaseUrl**. Приложение проверяет сертификат системными средствами Android. HTTP без TLS запрещён, перенаправления отключены. Запросы чтения идут без ключа редактора.

На всю операцию чтения отведено 15 секунд, на установление соединения — 5 секунд, на ожидание данных в сокете — 10 секунд. Отмена вызывающей корутины прерывает запрос. [Таймауты Ktor](https://ktor.io/docs/client-timeout.html).

## Как обрабатываются ошибки

| Ошибка | Когда возвращается |
| --- | --- |
| Сбой сети | Ошибка DNS, соединения или TLS |
| Тайм-аут | Истёк лимит ожидания, HTTP 408 или 504 |
| Набор не найден | HTTP 404 с кодом deck_not_found при чтении набора |
| Каталог недоступен | HTTP 429 и ошибки 5xx, кроме 504 |
| Запрос отклонён | Остальные ошибки 4xx |
| Некорректный ответ | Неверный JSON, поля, UUID или статус ответа |

## Проверка

Прошли 11 тестов клиента через [MockEngine](https://ktor.io/docs/client-testing.html) и 5 тестов мапперов. Полный прогон дал 60 успешных JVM-тестов и 5 тестов на Android 14. Debug APK собран, ktlint прошёл. Android Lint показал 0 ошибок и 17 предупреждений.

Отдельно выполнено ручное чтение по HTTPS. Оба маршрута вернули 200. В каталоге был один набор с 12 карточками. Подключение сетевых данных к экрану каталога запланировано на практику 17.

2. **.\gradlew.bat :app:assembleDebug :app:lintDebug :ktlintCheck**
