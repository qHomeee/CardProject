# Практика 19 Редактор наборов и карточек

Новый набор создаётся в разделе «Мои наборы». После сохранения открывается его содержимое. В редакторе можно изменить сведения о наборе, добавить карточку или открыть существующую карточку для правки. Пустой набор можно сохранить.

## Проверка полей

| Поле | Требование |
| --- | --- |
| Название | Обязательно, до 100 символов |
| Описание | Необязательно, до 500 символов |
| Вопрос | Обязательно, до 1000 символов |
| Ответ | Обязательно, до 1000 символов |

При сохранении валидатор удаляет внешние пробелы, проверяет длину в кодовых точках Unicode и отклоняет недопустимые символы. Ошибка появляется у соответствующего поля. Введённый текст остаётся в форме, в том числе при ошибке записи.

Изменение текста карточки сбрасывает её расписание. Правка названия или описания набора оставляет расписание карточек прежним. Для удаления набора или карточки нужно подтвердить удаление связанных данных повторения.

Сведения и карточки хранятся в Room. Редактор открывается для собственных наборов. [Макеты редактора в Figma](https://www.figma.com/design/vGsWHmxJCV73DQ0EIwDe4Z?node-id=23-758).

## Проверка в авиарежиме на Android 14

| Действие | Результат |
| --- | --- |
| Сохранить набор без названия или карточку без ответа | Поле подсвечивается. Остальной ввод сохраняется. |
| Повернуть экран, пока форма открыта | Текст описания остаётся при переходе в альбомный режим и обратно. |
| Изменить карточку из редактора набора | Редактор показывает новый ответ и сохраняет черновик названия. |
| Вызвать сбой записи Room и повторить | Черновик остаётся. После повтора в базе одна запись. |
| Перезапустить приложение | Сохранённый набор и карточка открываются из «Моих наборов». |
| Отменить, затем подтвердить удаление | При отмене данные остаются. Подтверждение удаляет выбранный материал. |
