# Практика 18 Просмотр и скачивание наборов

Карточка набора в каталоге и в разделе «Мои наборы» открывает экран с названием, описанием, количеством карточек, вопросами и ответами. В маршруте передаётся только идентификатор выбранного набора.

| Источник | Чтение и действия |
| --- | --- |
| Каталог | HTTPS. Можно скачать набор или открыть уже сохранённую копию. |
| Скачанный набор | Room. Карточки доступны без сети, удаление копии требует подтверждения. |
| Свой набор | Room. Отображаются карточки или сообщение «Карточек пока нет». |

Скачивание получает полный набор. Room записывает набор, карточки и начальное расписание одной транзакцией. При сбое предпросмотр остаётся открыт и доступен повтор. После успешной записи открывается локальная копия. Повторное обращение к тому же набору предлагает открыть существующую копию.

В диалоге удаления указано, что с устройства исчезнут карточки и история их повторений. Кнопка «Отмена» оставляет копию на месте.

Экран использует цвета и компоненты дизайн-системы. Кнопка скачивания остаётся доступна при прокрутке карточек. [Макеты экрана набора в Figma](https://www.figma.com/design/vGsWHmxJCV73DQ0EIwDe4Z?node-id=23-385).

## Проверка на Android 14

| Действие | Результат |
| --- | --- |
| Открыть «Столицы Европы» с VPS | Показаны сведения о наборе и 12 карточек |
| Отключить сеть перед скачиванием | Предпросмотр остался открыт. Появилась кнопка повтора. |
| Вернуть сеть и повторить скачивание | Открылась сохранённая копия |
| Перезапустить приложение в авиарежиме | В «Моих наборах» одна копия. Все 12 вопросов и ответов совпали с данными VPS. |
| Отменить удаление, затем подтвердить | При отмене копия осталась. После подтверждения копия исчезла из локального списка. |

Инструментальный тест с Room и подменным каталогом проверяет отказ запроса, отсутствие частичной копии и двойное нажатие. Отдельный тест проверяет отображение вопроса и ответа своего набора после пересоздания Activity.

Прошли 67 JVM-тестов и 19 инструментальных тестов. Debug APK собран, ktlint прошёл. Android Lint показал 0 ошибок и 26 предупреждений.
