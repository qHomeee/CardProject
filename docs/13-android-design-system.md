# Практика 13 Тема и компоненты Запомни

Приложение использует светлую или тёмную палитру по настройке Android. В обеих темах одинаковые роли цветов, шесть текстовых стилей на основе Roboto, общие отступы и скругления. Экран «Мои наборы» использует карточки наборов и сообщения о загрузке и пустом списке.

## Компоненты Compose

| Компонент | Реализация | Состояния |
| --- | --- | --- |
| Кнопка | ZapomniButton | Основная, дополнительная, недоступная, сохранение |
| Поле ввода | ZapomniTextField | Пустое, заполненное, фокус, ошибка, недоступное |
| Переключатель | ZapomniSwitch | Включён, выключен, недоступен |
| Нижняя панель | ZapomniNavigationBar | Каталог, наборы, настройки |
| Карточка набора | DeckCard | Серверная, своя, скачанная |
| Карточка занятия | StudyCard | Вопрос и открытый ответ |
| Сообщение | StatusMessage | Загрузка, пусто, офлайн, ошибка, жесты недоступны |

Цвета и типографика сверены с [основами в Figma](https://www.figma.com/design/vGsWHmxJCV73DQ0EIwDe4Z?node-id=3-2) и файлом 05-tokens.json. Для [пустого сообщения](https://www.figma.com/design/vGsWHmxJCV73DQ0EIwDe4Z?node-id=6-38) использована исходная иконка из Figma. Остальные компоненты реализованы по сохранённой спецификации и макетам проекта после достижения лимита прямых запросов Figma Starter.

## Поведение и проверка

Кнопка показывает индикатор сохранения и блокирует нажатия до завершения операции. Ошибка поля доступна в семантике элемента, а введённое значение сохраняется. Переключатель принимает нажатие по всей строке. Вкладки объявляют своё состояние выбора. Минимальная зона нажатия у кнопок, переключателя и вкладок составляет 48 dp.

В **DesignSystemPreview.kt** доступны семь примеров для Android Studio. На эмуляторе Android 14 проверены светлая и тёмная темы и прокрутка образцов при масштабе текста 200 %. При крупном шрифте действия и вкладки размещаются по одному в строке. Минимальный контраст среди 13 проверенных пар текста и фона составил 5,05:1 в светлой и 6,25:1 в тёмной теме.

## Результаты

Собран debug APK. Прошёл JVM-тест Koin и пять инструментальных тестов. Проверены запуск «Моих наборов», блокировка сохранения, ввод при ошибке, переключатель и вкладки, показ ответа. ktlint завершился без нарушений. Android Lint завершился без ошибок.

Команды для повторной проверки из папки android приведены ниже.

1. **.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest**
2. **.\gradlew.bat :ktlintCheck :app:lintDebug**
3. **.\gradlew.bat :app:connectedDebugAndroidTest**
