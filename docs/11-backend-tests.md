# Практика 11 Тестирование сервера каталога

## Тест-план

Проверяем чтение и изменение каталога по OpenAPI, валидацию входных данных и защиту записи.

**Модульные проверки.** Pytest вызывает модели, правило доступа редактора и обработчики напрямую. Сбои базы моделируются с помощью исключений.

**Проверки API.** Клиент FastAPI вызывает маршруты внутри процесса. Для CRUD используется локальная PostgreSQL 18.7. Alembic применяет миграцию в отдельной схеме для каждого интеграционного теста. После теста схема удаляется.

**Тестовые данные.** Используются наборы по географии, тестовый ключ редактора, строки на границах допустимой длины, переносы строк и совпадающие названия наборов. Версии библиотек берутся из uv.lock.

**Критерий приёмки.** Не менее десяти модульных тестов проходят отдельно. Полный прогон завершается без ошибок и пропусков. Ответы API совпадают с ожидаемыми статусами, кодами ошибок и правилами сохранения данных.

## Порядок запуска

1. Перейдите в папку **backend** и выполните **uv sync --locked**.
2. Запустите модульные тесты командой **uv run --locked python -m pytest -q tests/unit**.
3. Для полного прогона задайте TEST_DATABASE_URL отдельной тестовой базы и выполните **uv run --locked python -m pytest -q**. Настройка базы описана в **backend/README.md**.

## Тест-кейсы модульных проверок

| ID | Действие и данные | Ожидаемый результат |
| --- | --- | --- |
| U01 | Передать название из 100 букв и описание из 500 букв с внешними пробелами. | Модель сохраняет 100 и 500 символов после обрезки краёв. |
| U02 | Передать название из 101 буквы, одни пробелы или число. | Модель отклоняет поле title и указывает соответствующую ошибку длины или типа. |
| U03 | Сохранить вопрос из 1000 символов с внутренним переносом. Передать ответ из 1001 символа. | Корректный вопрос сохраняет перевод строки. Слишком длинный ответ отклоняется. |
| U04 | Передать один заголовок X-Editor-Key с заданным ключом. | Проверка допускает операцию записи. |
| U05 | Опустить ключ, передать неверный или продублировать заголовок. | Проверка отказывает с кодом 401 и editor_required. |
| U06 | Смоделировать тайм-аут пула и ошибку выполнения SQL. | Тайм-аут даёт 503, ошибка SQL даёт 500. Ответы сохраняют общую схему. |

Фактический результат по U01–U06 — успешно. Тесты в **backend/tests/unit** также проверяют пустое описание, запрет служебных полей и недопустимые символы в карточке.

## Тест-кейсы API и PostgreSQL

| ID | Действие и данные | Ожидаемый результат |
| --- | --- | --- |
| A01 | С ключом создать набор и карточку, обновить их, прочитать и удалить. | Создание даёт 201 с Location, чтение и изменение дают 200, удаление даёт 204 без тела. |
| A02 | Искать «STRASSE 50%_» с пробелами по тестовому каталогу. | Регистр игнорируется, % и _ ищутся буквально, наборы с разными ID сохраняются в выдаче. |
| A03 | Запросить карточку по пути другого набора. Затем удалить её набор. | Чужой путь даёт 404. Удаление исходного набора каскадно удаляет его карточки. |
| A04 | Отправить незавершённый JSON и название из 101 буквы в POST /api/v1/decks. | Оба запроса дают 422. Ответ указывает body или body.title. |
| A05 | Выполнить PATCH /api/v1/decks. | Ответ 405 содержит method_not_allowed и заголовок Allow. |
| A06 | Сравнить схему OpenAPI приложения с зарегистрированными маршрутами. | Совпадают девять операций, статусы успеха и правила авторизации. |

Фактический результат по A01–A06 — успешно. Всего прошли **22 модульных теста** и **33 проверки в полном прогоне** на Python 3.13.15 и PostgreSQL 18.7. Полный прогон занял 1,58 секунды.
